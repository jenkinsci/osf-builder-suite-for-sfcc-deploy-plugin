Two Factor Auth credentials of type "OSF Builder Suite Two Factor Auth" for the SFCC instance where this build should be deployed. Select "- none -" if you deploy to a instance that does not require two factor auth.

The "Server Certificate" of these credentials is trusted in addition to the certificate authorities that the JVM running this Jenkins node already trusts, so an instance using a certificate issued by a public CA keeps working after that certificate is renewed. A server certificate that is expired or not yet valid is ignored with a warning instead of failing the build.
